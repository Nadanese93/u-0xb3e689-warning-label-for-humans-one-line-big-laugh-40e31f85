# Warning Label for Humans: One Line, Big Laugh

One single-line safety warning label for humans, 70 characters:

> WARNING: This human's 'I'll start Monday' has been running since 2019.

`main.py` (Python 3 stdlib only, no network) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing
newline. Run it with `python3 main.py`.
